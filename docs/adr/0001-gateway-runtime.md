# ADR 0001：Gateway 运行时选型

- 状态：待决；Node.js 仅用于工作区原型
- 日期：2026-11-22

## 背景

Gateway 需要管理本地设备、网络连接、调试工具适配、串口和 OTA。生产选型必须比较运行资源、开发与增量构建成本、跨平台部署和现有调试生态；不能只根据语言偏好决定。

## 当前决定

生产 Gateway 语言暂不锁定。工作区用 Node.js 内置 HTTP 能力实现一个可运行的本机模拟原型，目的是先验证设备注册、能力查询、会话占用、数据交换和断线释放。该原型不是生产实现，也不作为固件传输协议。

首轮正式候选保留 Rust 与 Go；如实测显示其他方案显著减少调试后端集成成本，可以加入比较。Rust 和 Go 均需使用同一组状态转换和 HTTP 负载实现最小等价实验，并在同一机器、冷/热缓存下各运行至少三次。

## 选择门槛

先验证 OpenOCD/pyOCD/probe-rs 接入路径、USB/Wi-Fi 需求和跨平台约束，再比较构建耗时、峰值内存、发布产物、Gateway 空闲资源与 1/5/20 个模拟设备的延迟。开发环境缺失时记录阻塞，不以原型语言替代正式决策。

## 重新评估

Go 工具链和 Rust 最小实验均可复现、并完成调试后端适配路径核验后，更新本 ADR 并确定唯一生产实现。不能以模拟负载结果宣称实体探针容量。
