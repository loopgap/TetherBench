# ADR 0003：共享 C5 的传输和资源所有权

日期：2026-11-26。状态：实现中，部分验证。此决定补充 ADR 0002 尚未确定的 C5 传输，不改变原型模拟 API。

使用 IDF 原生 TLS HTTP 服务承载 24 字节头和最多 4096 字节负载。固定缓冲、单事务执行避免每个总线操作都创建任务或堆队列。DAP 保持 Arm 原生命令，UART/SPI/I2C 使用长度明确的二进制负载；BUS 是有界事务，不代表持续串流。复用 SDK 的 TLS、NVS、驱动和 OTA，不增加序列化依赖或独立管理服务。

主机在发送令牌前核对预置证书。租约统一拥有引脚和总线；到期释放。OTA 只写非运行槽，持久化已签名任务与检查点，复用 IDF 确认/回滚机制。应用签名不能替代量产安全启动和硬件防降级。

Arm 官方核心固定提交并保留许可证。跨工程入口在 `contracts/probe-c5.md`；C5 专属源代码、工具、测试和详细文档在 `firmware/probe-c5/`。

双频先采用双方最差链路评分、滞回、驻留和超时回退。没有训练数据、CSI 采集与实测收益，不在无 PSRAM 的 C5 引入学习模型。自动联合测量及真实切频仍未完成。
