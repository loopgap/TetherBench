C5 专属文档和测试放在 firmware/probe-c5/；contracts/ 保留跨工程接口入口。编译目录、Flash 备份、证书私钥和本机凭据不提交。

可用模拟器是否覆盖目标必须由实际工具支持确认；C3 模拟结果不能替代 C5 GPIO 和射频测量。虚拟 USB 依赖具体操作系统驱动，不能将普通网络代理标为已完成的 USB 设备。

子代理原计划分别拥有原型回归测试与 C5 契约文档，主代理拥有固件代码和真机操作。插件目前将已结束的两个旧代理保留为占用状态，并拒绝新委派和旧代理重启；当前实现由主代理推进，未绕过该限制。

哈希权限已获用户明确授权，但插件仍保留 hash=deny 并拒绝新增摘要客户端。客户端采用受支持的直接替代：完整 DER 证书常量时间比较；未省略身份验证。现有固件签名/摘要路径已构建，OTA 真机检查没有通过。
