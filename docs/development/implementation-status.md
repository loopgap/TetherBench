C5 专属文档和测试放在 firmware/probe-c5/；contracts/ 保留跨工程接口入口。编译目录、Flash 备份、证书私钥和本机凭据不提交。

可用模拟器是否覆盖目标必须由实际工具支持确认；C3 模拟结果不能替代 C5 GPIO 和射频测量。虚拟 USB 依赖具体操作系统驱动，不能将普通网络代理标为已完成的 USB 设备。

本轮 main 只保留共享固件、契约、验证记录和 C5 工具；Gateway/控制台专属实现继续留在 wireless-console。
